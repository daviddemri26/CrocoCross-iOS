# Security reporting

For a suspected security issue, contact repository owner [@daviddemri26](https://github.com/daviddemri26) through an existing private collaboration channel. If GitHub offers **Security → Report a vulnerability** for this repository, use that private form. Private vulnerability reporting is not assumed to be enabled.

Do not put credentials, player identifiers, private save files or exploit details in public issues. Include the affected commit/build, impact and minimal reproduction steps with sensitive values removed. No response-time commitment is currently published.

This is a development candidate. Fixes target the current development branch; there is no published supported-release matrix yet.
